# Support

For roadmap, cross-repository planning, and internal delivery status, use the [sonus-auris Linear project](https://linear.app/denman/project/githubcomsonus-auris-a557165528ef).

For a reproducible bug or a scoped feature request, open an issue in the affected repository using the organization issue forms. Include the repository, version or commit, platform/device, permission state, expected behavior, actual behavior, reproduction steps, impact, and sanitized logs.

Do not post vulnerabilities, credentials, recordings, transcripts, personal data, biometric data, or production data in public support channels. Follow [`SECURITY.md`](SECURITY.md) for private reporting.

For reproducible product or development problems, use the affected repository's issue tracker and include environment, version or commit, expected behavior, actual behavior, and a minimal reproduction. Use discussions where a repository enables them for open-ended questions.

Do not post credentials, private logs, customer data, legal records, or vulnerability details. Security reports must follow [`SECURITY.md`](SECURITY.md).

Planning context for the GitHub owner is tracked in [github.com/sonus-auris](https://linear.app/denman/project/githubcomsonus-auris-a557165528ef), although external contributors may not have access. Repository-local support documentation may define a narrower channel or support policy.
