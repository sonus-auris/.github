# Support

For roadmap, cross-repository planning, and internal delivery status, use the [sonus-auris Linear project](https://linear.app/denman/project/githubcomsonus-auris-a557165528ef).

For a reproducible bug or a scoped feature request, open an issue in the affected repository using the organization issue forms. Include the repository, version or commit, platform/device, permission state, expected behavior, actual behavior, reproduction steps, impact, and sanitized logs.

Do not post vulnerabilities, credentials, recordings, transcripts, personal data, biometric data, or production data in public support channels. Follow [`SECURITY.md`](SECURITY.md) for private reporting.
