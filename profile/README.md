# sonus-auris

Sonus Auris develops privacy-conscious audio capture, indexing, retrieval, evidence, transcription, and cross-platform recording systems.

## Planning and governance

- Canonical Linear project: https://linear.app/denman/project/githubcomsonus-auris-a557165528ef
- Organization defaults and policies: https://github.com/sonus-auris/.github
- Agent-safety policy: https://github.com/sonus-auris/.github/blob/main/AGENTS.md
- Contribution guide: https://github.com/sonus-auris/.github/blob/main/CONTRIBUTING.md
- Security policy: https://github.com/sonus-auris/.github/security/policy

Every repository should link substantial work to Linear, resolve conflicts semantically with full historical and cross-repository context, preserve user recordings and data non-destructively, and maintain a root `AGENTS.md` that preserves the organization-wide destructive-operation blacklist.
